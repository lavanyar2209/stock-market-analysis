##Stock Market Analysis and Prediction Using Machine Learning

## Overview
The Stock Market Analysis and Prediction project is a Machine Learning-based system that analyzes historical stock market data and predicts future stock closing prices. The project helps investors and analysts understand market trends through data visualization and predictive analytics.

## Objectives
- Analyze historical stock market data.
- Visualize stock market trends using graphs.
- Train Machine Learning models for prediction.
- Compare algorithm performance.
- Predict stock closing prices using user input.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Joblib
- Google Colab

## Dataset Features
- Open Price
- High Price
- Low Price
- Close Price
- Volume

## Data Visualization
- Scatter Plot
- Histogram
- Trend Analysis

## Machine Learning Algorithms
### Linear Regression
Used to predict continuous stock prices based on historical data.

### Random Forest Regression
Uses multiple decision trees to improve prediction accuracy.

## Performance Metrics
- R² Score
- Mean Squared Error (MSE)

→ Model Evaluation

→ Model Saving
